## P39 — Rehearse an upgrade

**Use when:** A supported transition needs real update evidence.

**Inputs:** Approved [W35](../worksheets/W35_Installed-Version_and_Upgrade_Plan.md#w35)/W19, exact old/new artifacts, permitted isolated fixtures, commands and limits.

```text
Rehearse [source state -> target] only within the supplied authorization and disposable environment. Identify artifacts and fixture provenance; create and validate the old installation, populate representative settings/data and preserve approved recovery material. Apply the real update mechanism, not only its migration helper. Verify meaning, identities, relationships, permissions, settings and workflows; restart and recheck. Exercise approved rerun, interruption/recovery and unsupported/refusal cases without risking real user data. Keep installation recovery separate from persistent-state recovery and account for writes after update. Preserve commands, versions, raw outputs, failures/retries, checks not run and limitations; register the transition's suite and release evidence. Stop if artifacts, authority or valid isolation are missing. Do not bypass signing, invent historical data provenance or claim release approval.
```
