## P17 — Review this change like a senior developer

**Use when:** A meaningful diff is ready for independent challenge.

**Inputs:** Exact diff/baseline, requirements, Change Brief and test evidence.

```text
Review the actual diff and relevant surrounding code for [change], not the author’s summary. Check requirement fit, correctness, scope, error/state/data handling, architecture, security, dependencies, tests, compatibility and documentation. Inspect deleted/disabled checks and unexpected files. For each material finding give location, triggering conditions, evidence, impact and a proportionate correction. Distinguish blockers from optional improvements and uncertainty. Do not rewrite code or expand scope. Report inspected artifacts, unrun checks and remaining limitations; AI review is not proof of correctness.
```
