## P28 — Session handoff between agents

**Use when:** A different session, tool or model will continue the work.

**Inputs:** Current repository/branch/commit, task scope, changes and evidence.

```text
Prepare a handoff for [task] using current repository evidence. Include exact root/branch/commit, uncommitted work and ownership, approved objective/non-goals, inspected paths, accepted decisions, unresolved assumptions, changes, tests with actual results, unrun checks, recovery/checkpoint, permissions and next safe action. Link canonical documents and artifacts; omit secrets and redundant chat history. Tell the receiving agent what to recheck against current state before editing. Do not claim remembered work is verified unless its evidence is available.
```
