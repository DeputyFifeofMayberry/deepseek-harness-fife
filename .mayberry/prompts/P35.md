## P35 — AI-feature readiness and evaluation

**Use when:** The product depends on runtime model behavior or a behavior-changing AI configuration update.

**Inputs:** Capability, deterministic baseline, prompts/model/retrieval/tools versions, fixtures, privacy constraints and existing results.

```text
Review [runtime AI feature] as a product dependency, not as coding assistance. Inspect its full configuration and evidence. Define allowed/forbidden behavior, deterministic safeguards, authorized grounding, output validation, tool permissions, privacy/cache boundaries, cost/latency limits and refusal/timeout/outage fallback. Plan representative, negative, adversarial and held-out cases with explicit rubrics, repeats where useful and human calibration of model graders. Separate schema validity from truth, transcripts from actual effects, and planned tests from executed results. Compare against the baseline without tuning away the evaluation. Return W33 with accept/hold/revise, evidence limits and required gates. Do not invoke paid models, access private data or execute consequential tools without authorization.
```
