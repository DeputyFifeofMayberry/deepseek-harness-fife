## P05 — Codebase X-Ray

**Use when:** You need a trustworthy mental model of a repository.

**Inputs:** Repository path, target revision and any known task.

```text
Inspect [repository] without editing, installing dependencies or running unapproved commands. Establish root, branch/commit, existing changes and applicable instructions. Read actual entry points, major modules, state/data ownership, persistence, integrations, configuration, build/test/package definitions and risky boundaries. Trace one successful and one failed user workflow in plain English. Cite inspected paths and symbols. Distinguish code inspection from executed evidence and mark uninspected areas. Return a concise map, contradictions, unknowns and the next safe check. Do not infer services or architecture from folder names alone.
```
