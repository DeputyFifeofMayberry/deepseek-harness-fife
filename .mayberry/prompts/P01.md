## P01 — Idea clarification

**Use when:** An idea is interesting but the real problem is unclear.

**Inputs:** Idea, observed situation, current workaround, constraints.

```text
Help clarify this software idea: [idea]. Use the supplied observations and constraints. Separate the user’s problem, desired outcome, proposed solution and unverified assumptions. Describe the smallest complete useful workflow and credible existing alternatives. Identify non-goals and the assumption most likely to invalidate the idea. Do not invent interviews, usage evidence or requirements. Ask only the missing question that materially changes the decision; otherwise label assumptions. Do not choose a technology stack or start implementation. Return a concise Project Canvas and the next useful evidence to collect.
```
