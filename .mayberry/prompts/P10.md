## P10 — Feature planning

**Use when:** A capability must fit the existing project.

**Inputs:** Requirement, milestone, repository and approved scope.

```text
Plan [feature] within [project requirement/milestone]. First inspect the affected current path and relevant canonical documents. State current behavior, desired behavior, evidence, assumptions and non-goals. Select Quick/Standard/Deep by consequences. Propose a small coherent approach with alternatives, affected files/interfaces/data, necessary permissions, acceptance and regression checks, recovery and Done. Identify gates before edits. Preserve unrelated work and do not add dependencies without justification. Return a Change Brief only; do not implement until its scope is authorized.
```
