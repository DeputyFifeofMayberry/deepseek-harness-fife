## P13 — Debugging investigation

**Use when:** A bug needs evidence before another fix.

**Inputs:** Expected/actual behavior, reproduction, environment and logs.

```text
Investigate [bug] without speculative edits. Establish expected versus actual behavior, affected version/environment and a minimal reproduction. Inspect the failing path, recent code/configuration/dependency/data changes and existing tests. Generate competing hypotheses, rank them by evidence and propose the cheapest safe discriminating experiment for each. State predictions before any authorized test. Preserve useful evidence and avoid real data or secrets. Distinguish confirmed cause, hypothesis and mitigation. Return findings, next experiment and only then a proposed smallest fix with regression checks.
```
