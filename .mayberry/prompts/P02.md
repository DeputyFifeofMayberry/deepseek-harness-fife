## P02 — Product definition

**Use when:** The problem is understood but scope and workflow need definition.

**Inputs:** Project Canvas, user evidence, constraints.

```text
Using [Project Canvas and evidence], define the product in plain English. Describe users, the main workflow, expected outcomes, constraints, necessary safety and explicit non-goals. Separate Now, Later and Not planned. Make the MVP a complete useful path, not a collection of disconnected screens. Identify failure states and uncertain product decisions. Explain why each Now capability is necessary. Do not manufacture demand or add speculative AI/cloud features. Return a product definition and unresolved decisions; do not implement.
```
