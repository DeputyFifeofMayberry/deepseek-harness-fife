## W25 — Learning and Teach-Back Review

**Purpose:** Turn AI assistance into usable understanding.

**Use when:** A new concept, consequential change or recurring misunderstanding. **Skip when:** An already understood trivial task adds no learning value.

| Prompt | Your response |
|---|---|
| **Relevant concept or system**<br>What do you need to understand for this decision? |  |
| **Prediction before the run**<br>What should happen and what evidence would change your explanation? |  |
| **Observed result**<br>Actual behavior, environment and relevant evidence. |  |
| **Explain without the agent**<br>How did the system work, what changed, and why was the approach chosen? |  |
| **Compare and correct**<br>What did your explanation miss? Verify against code/source/results. |  |
| **Vocabulary worth preserving**<br>A plain-English definition and a real project example—not a copied jargon list. |  |
| **Later recall prompt**<br>A question or architecture redraw to revisit after a useful interval. |  |

**Close the worksheet when:** You can apply the concept to a new decision, not merely repeat its definition.

**Use with:** Chapters 1/18; Technical Literacy Field Guide.
