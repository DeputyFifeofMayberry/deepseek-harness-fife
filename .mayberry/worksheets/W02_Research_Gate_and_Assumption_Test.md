## W02 — Research Gate and Assumption Test

**Purpose:** Turn uncertainty into a decision.

**Use when:** An unknown can change feasibility, scope, architecture, safety or cost. **Skip when:** The relevant fact is already verified and stable for this version.

| Prompt | Your response |
|---|---|
| **Decision and question**<br>What must be decided, and what information could change it? |  |
| **Assumption and consequence**<br>What are we assuming? What happens if it is wrong? |  |
| **Evidence plan**<br>Relevant primary source/version or controlled experiment and fixture. |  |
| **Success, failure and stopping rule**<br>What result supports/rejects the option? Set a reasonable investigation boundary. |  |
| **Observed result and source**<br>Record date/version, method, output and evidence location. |  |
| **Limits and remaining unknowns**<br>What was not checked, and why does that matter? |  |
| **Gate decision and owner**<br>Proceed / conditional / change direction / stop. Name the next action and authority. |  |

**Close the worksheet when:** The outcome is a decision with explicit uncertainty, not a collection of links.

**Use with:** Chapter 3; [D02](../DECISION_AIDS.md#d02); [P03](../prompts/P03.md#p03)/P12.
