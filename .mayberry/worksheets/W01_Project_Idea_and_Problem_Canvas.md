## W01 — Project Idea and Problem Canvas

**Purpose:** Decide what problem is worth solving.

**Use when:** A new idea or a material product-direction change. **Skip when:** A small task already covered by an accepted product contract.

| Prompt | Your response |
|---|---|
| **User and situation**<br>Who experiences the problem? Describe a recent real occurrence. |  |
| **Obstacle and consequence**<br>What gets in the way, and what is lost or made difficult? |  |
| **Current workaround and alternatives**<br>How is the job done today? Could an existing tool suffice? |  |
| **Desired outcome and evidence**<br>What observable improvement matters, and how will you compare it? |  |
| **Constraints and non-goals**<br>Time/cost/platform/data restrictions; what you will not build. |  |
| **Smallest complete useful workflow**<br>Beginning, user action, result and necessary protection. |  |
| **Most consequential assumption**<br>What could make the idea fail? Link the next research gate. |  |

**Close the worksheet when:** The problem is understandable without naming a preferred framework.

**Use with:** Chapters 2–3; [P01](../prompts/P01.md#p01)/P02; [W02](W02_Research_Gate_and_Assumption_Test.md#w02)/W03.
