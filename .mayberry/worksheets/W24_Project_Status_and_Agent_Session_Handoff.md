## W24 — Project Status and Agent Session Handoff

**Purpose:** Resume from evidence rather than chat memory.

**Use when:** A session/model/tool handoff, work pause or integration handoff. **Skip when:** A short uninterrupted task with all relevant state already verified.

| Prompt | Your response |
|---|---|
| **Repository and working state**<br>Exact root/branch/commit, uncommitted changes and ownership of concurrent work. |  |
| **Objective and approved scope**<br>Product/milestone/brief; non-goals; permissions and protected actions. |  |
| **Inspected evidence and decisions**<br>Paths/symbols, source versions, accepted rationale and unresolved assumptions. |  |
| **Changes and checks**<br>What changed; exact procedures/results; artifact identities; explicitly unrun checks. |  |
| **Open issues and next safe action**<br>Blocking/nonblocking; owner; what must be inspected before continuing. |  |
| **Canonical links and recovery**<br>Project/docs/issues, checkpoint and relevant recovery references. |  |
| **Receiver reconciliation**<br>Confirm current state matches; resolve contradictions before edits. No secrets in this record. |  |

**Close the worksheet when:** A receiver can identify the next safe action without trusting an unseen conversation.

**Use with:** Chapters 13/18; [P27](../prompts/P27.md#p27)/P28.
