## W15 — Dependency Evaluation

**Purpose:** Decide whether a new obligation is justified.

**Use when:** A material new package, platform or external service. **Skip when:** Routine existing-version inventory belongs in manifest/lockfile.

| Prompt | Your response |
|---|---|
| **Need and alternatives**<br>Required capability; existing platform/package/no-dependency option. |  |
| **Exact identity and version**<br>Official source/repository, publisher and version actually evaluated. |  |
| **Fit evidence**<br>Supported runtime/API, representative experiment and known limitations. |  |
| **Security and permissions**<br>Install/build/runtime actions, effects introduced through transitive dependencies, known reports and data exposure. |  |
| **License, cost and obligations**<br>Applicable terms, distribution limits and material uncertainty requiring review. |  |
| **Maintenance and exit**<br>Update owner, compatibility risks, replacement/removal path and revisit trigger. |  |
| **Decision and approval**<br>Accept / defer / reject; rationale, constraints and validation after integration. |  |

**Close the worksheet when:** Need, exact identity/version, fit evidence, security/permissions including transitive exposure, license/cost, maintenance/exit path, and an accept/defer/reject decision with validation conditions are recorded.

**Use with:** Chapters 3/12; [D06](../DECISION_AIDS.md#d06); [P19](../prompts/P19.md#p19).
