## W07 — Consequential Decision Record / ADR

**Purpose:** Preserve why a significant choice was made.

**Use when:** A choice constrains architecture, storage, interfaces, security or future change. **Skip when:** A routine local choice is obvious and inexpensive to reverse.

| Prompt | Your response |
|---|---|
| **ID, title, owner and status**<br>Proposed / accepted / rejected / superseded; date and related records. |  |
| **Context and evidence**<br>Requirements, constraints and actual pressure requiring a decision. |  |
| **Credible alternatives**<br>Include the simplest adequate option and deferral when plausible. |  |
| **Decision and rationale**<br>Why this option at the project’s actual scale? |  |
| **Consequences and recovery**<br>Benefits, new obligations, limitations and reversal/transition cost. |  |
| **Validation and revisit trigger**<br>Evidence needed now; observed conditions that would change the choice. |  |
| **Supersession**<br>Link replacement decisions; preserve the historical rationale. |  |

**Close the worksheet when:** The record explains why, not merely which tool was chosen.

**Use with:** Chapters 5/13; [D16](../DECISION_AIDS.md#d16); [P07](../prompts/P07.md#p07)/P08.
